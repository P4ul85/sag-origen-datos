# SAG Origen — datos públicos

`datos.json` contiene la información pública que la app **SAG Origen** descarga al abrirse para mantenerse al día sin reinstalar:
novedades del SAG, catálogo de documentos oficiales (sag.gob.cl y otras fuentes públicas), resúmenes de inspección y el registro de cambios de Requisitos por país.

Se actualiza automáticamente desde el repositorio privado de la app. No editar a mano.
